# 墨习 · 写法资料库

v0.6 将日常记录简化为：选择笔画、偏旁或间架结构，填写写法内容，查字后自动展示相关资料。页面、字库和动画资源均自托管，个人资料保存在当前浏览器。

## 使用方式

在“资料库”点击唯一的“添加写法”，选择记录对象，填写内容即可。标题自动生成，来源与例字选填，不必填写位置、层级或分类。同一对象的记录集中展示，长横与短横旧记录集中在横画下，各条原文分别保留，不自动合并或覆盖；复合笔画单独整理。旧整字记录、分类及其它附加字段继续保留，可在旧记录区域查看或编辑。

查“河”时，页面自动展示相关横画、氵、可等记录。间架结构分为基础结构（左右、上下等）与具体布局（左窄右宽、上紧下松等）。配置 API 后，由 AI 分析并按规范标签关联资料，附观察依据并标为候选参考；没有足够依据时允许不返回布局标签。完整例子见[使用指南](docs/USER_GUIDE.md)。

## AI 接口

在查字页打开“AI 接口设置”，填写可信服务的完整 HTTPS 调用地址、模型名和 API 密钥。需要 Chat Completions 兼容协议，并须由服务端允许浏览器跨域调用（CORS）。可以开启查字自动分析，或手动触发；接口、模型和密钥可随时修改，旧请求取消，新配置立即生效。本站不提供模型代理或共享密钥，模型调用可能收费。

配置与密钥仅在本次页面内存使用，刷新后重新填写，不进入 GitHub、浏览器存储或笔记备份。只发送当前汉字及公开字库的部首、拆字与基础结构参考，不发送私人记录、个人修订或 PDF。AI 结果不自动保存为笔记，不是教材引文、页码证据、规范认证或书家风格判断，不覆盖个人修订。

## 数据与范围

- Make Me a Hanzi / Arphic 数据快照含9574条字形及笔画轨迹记录，包含简繁体；不代表覆盖全部汉字或所有地区规范。缺失轨迹不使用模型或普通字体补造。
- CNChar3.2.6提供8776字的整字笔画类型参考，另外798字保持未知。它用于一次检索全部相关写法，不依赖动画正在播放第几笔。
- 有限逐笔名称表覆盖25字；扩展CNChar笔顺名称序列为待核对参考，目前8610字满足名称数量与动画笔画数一致的检查。数量一致不能保证两库顺序一致；歧义名称作为候选，数量不符不套用，不根据轨迹猜名。
- 偏旁和结构资料属于字库参考；含未知拆分时保留不确定性。氵与水、扌与手等不同字形分别匹配，固定俗名关联对应字形。
- 动画不是卢中南或其他书家真迹，界面宋体只用于排版，中线不代表笔锋、力度或具体运笔方法。

原始教材PDF和练习照片不随网站发布。新版不提供PDF导入、AI对话或临摹画板入口；旧教材摘要、PDF.js及可选Worker源码保留于仓库及历史版本，但不进入当前构建。

## 备份

个人资料不会自动云同步。请在“数据管理”导出JSON并确认保存；换设备时导入，核对新增、重复与冲突后确认合并。重复导入会去重；同ID冲突可保留本地、采用导入或复制。存储失败时，先导出内存资料再关闭页面。

新版导出使用schemaVersion4，支持布局记录，兼容导入笔记备份1、2、3、4。新备份请使用v0.6或更新网页导入。v0.1学习记录是另一种格式，请保留原文件。存储键保持不变，旧正文、标题、来源、分类、位置、层级与条件保留，升级不清除资料。备份不包含整套字库、PDF或AI配置。

## 开发与测试

需要Node.js24或更新版本，前端无须安装npm运行时依赖。

```powershell
npm test
npm run build
npm run preview
```

打开http://127.0.0.1:4173，通过HTTP运行，不能双击HTML。预览器仅提供dist，支持`--port 8000`，Ctrl+C停止。

`npm run test:ui`是可选DOM集成测试，需要独立安装的jsdom26.1.0，可用MOXI_TEST_DEPS指定目录。它执行实际页面、模块及字库，覆盖简化记录、旧备份、分组、AI标签、取消切换、存储失败和真实动画库SVG创建；不能替代真实浏览器布局、动画帧与触控检查。模型接口通过注入模拟响应测试，真实API仍需用户配置后验证。

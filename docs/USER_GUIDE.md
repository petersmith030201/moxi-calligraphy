# 墨习使用指南

墨习有“查字”“知识库”“数据管理”三个页面。先观察字形，再把自己的学习记录保存为笔记；以后查其他字时，系统按规则展示可关联的原文。它不会自动把笔记改写为新的教学结论。

## 分清四种笔记用途

| 用途 | 适合记录什么 | 对象示例 |
| --- | --- | --- |
| 整字 | 某一个字的完整观察 | 永、橋 |
| 部件 | 一个字里可辨认的组成部分 | 氵、木、可 |
| 结构 | 部分之间的组合方式 | 左右结构、上下结构 |
| 笔画 | 基本笔画或复合笔画的学习记录 | 横、长横、竖、横折钩 |

“部件”是组成汉字的部分。例如“河”可拆为左侧“氵”和右侧“可”；部首是查字分类所用的概念，“河”的部首是“氵”，两者并不等同。笔画是组成字形的一次书写轨迹，“横”适合记在“笔画”用途里。

“我的分类”由你命名，用来整理笔记，例如“偏旁练习”“长横练习”“待整理”。用途与分类分别填写：一条用途为“笔画”的笔记，可以归到“长横练习”分类。已经建立的笔记也可以点击“编辑”重新分类，留空显示“未分类”。

## 例一：记录基本笔画，再按分类找回

1. 进入“知识库”，点击唯一的“新建笔记”按钮。
2. 标题填“长横观察”，用途选“笔画”，适用对象填“横”，我的分类填“长横练习”。
3. 正文可先写：“临写前先比较这一横的长度、倾斜和起止位置，再对照所选范字检查。”这是操作示例，**不是教材原文，也不是已经审定的写法**。来源填写自己的观察，或如实记录教材名称、页码。
4. 保存后，再建一条“短横观察”分类的笔记，记录另一段自己确认过的内容。
5. 回“查字”输入“木”，点“下一笔”观察第一笔。已提供名称参考时会显示“横”；也可在“笔画名称”中手动选择或填写“横”。
6. 查看“当前笔画 · 相关笔记”。系统列出所有分类名含“横”的笔记，并保留正文原文、来源和适用条件。笔画用途中对象恰好为“横”的笔记，即使未分类，也会作为名称精确匹配列出。

分类关联会查所有用途，不限“笔画”用途；分类为“长横练习”“短横观察”“横折对照”的内容都能被“横”找回。每条结果显示命中的分类关键词，便于你判断是否适用。

| 当前笔画名称 | 分类文字命中规则 |
| --- | --- |
| 横 | 分类名包含“横” |
| 竖 | 分类名包含“竖” |
| 撇、捺、点、提、折、钩 | 各按对应字匹配分类名 |
| 长横、短横 | 都含“横”，因此均检索含“横”的分类 |
| 横折钩 | 分类名含“横”“折”或“钩”任意一项 |

这是文字关联，所有结果均为**相关候选**。分类名里含“横”，不代表其中记录的横折、短横或其他写法适用于当前这一笔；系统也不据此判断实际轨迹的长短。只有标题或正文含“横”、分类与笔画对象未命中的笔记，不会被该区域的规则找到，可用知识库搜索框检索。

## 例二：跨汉字复用部件笔记

1. 查“河”，查看左侧“氵”和右侧“可”的拆分参考；若资料不适合你的教学拆分，可手动修订并保存为个人资料。
2. 在“知识库”新建笔记，用途选“部件”，对象填“氵”，位置选“左侧”，层级选“仅最外层部件”，分类可填“偏旁练习”。
3. 写下自己的观察和来源，必要时在“适用条件”说明限制。
4. 再查“江”或“河”，在关联笔记中查看记录。条件需要判断、结构不确定时，系统将其列为候选；部件位置和层级不符时不会直接套用。查“水”也不会自动当成“氵”。

整字、部件和结构仍按各自对象及位置等规则匹配；更改分类不改变这类匹配。“当前笔画”区域另按上表查分类，它与整字、部件、结构的匹配分开显示。

## 笔顺与笔画名称的范围

站点包含 9574 条开源字形与轨迹记录，简体和繁体按各自字符查找，不表示覆盖全部汉字或所有地区规范。输入未收录字时，可以记录或修订个人资料，但不会补造动画。

逐笔名称目前仅覆盖少量常用字，取自 CNChar 名称参考，并与当前轨迹进行有限核对。来源存在多个名称或无法确认时留空；未知名称不会根据轨迹猜测。你可以手动选择名称来查相关笔记，这次调整只在本次查字使用，不修改上游数据，也不作为独立资料导出。保存好的笔画笔记和分类照常导出。

动画参考字形来自开源字库，不是卢中南或其他书家的真实字迹。中线用于观察运动方向，不代表笔锋、力度或具体运笔方法。

## 备份、换手机与导入

个人笔记保存于当前设备、浏览器与站点来源下，不会自动同步到其他手机，也不会随着代码更新提交到 GitHub。

1. 在“数据管理”点击导出，可备份全部或勾选的笔记。确认文件已保存；备份包含笔记用途、分类、正文、来源及选定的个人修订，不包含整套字典和动画数据。
2. 在另一台手机或浏览器打开同一网站，导入该 JSON 文件。先查看新增、重复和冲突预览，再确认合并；冲突可以保留本地、采用导入或另存一条笔记。
3. 导入后到“知识库”检查笔记数量、分类和正文。重复导入同一备份会识别重复内容，不应不断增加相同记录。

v0.4 导出格式为 `schemaVersion: 3`，仍可导入本笔记系统的 v1、v2 备份；v1 未填写分类的内容归到“未分类”。更早 v0.1 的学习记录属于另一种格式，请保留原文件，不要把它当成笔记备份强行导入。新版备份包含“笔画”用途时，应使用 v0.4 或更新网页导入。

清除浏览器数据、使用无痕窗口或更换域名都可能让原笔记不可见，重要记录请及时导出。若页面提示存储失败，数据可能只留在内存，应立即导出备份并确认下载后再关闭或刷新。

# 墨习使用指南

播放时，已有限核对的笔画直接显示名称；其他名称来自 CNChar 笔顺序列时，显示“名称参考（待核对）”，并提示与动画来源不同，顺序仍可能有差异。多个叫法作为候选并列。名称数量与动画笔画数不一致或没有来源时，显示“暂无逐笔名称数据”，不据此编造名称。当前有 8610 字满足参考序列数量检查；这不是全面审校数量。

墨习有“查字”“知识库”“数据管理”三个页面。保存自己的观察后，查字会自动汇总可借鉴的原文记录；不必逐笔选择。可选 AI 用于单独分析间架结构，不会替你改写笔记。

## 四种笔记用途

| 用途 | 适合记录什么 | 对象示例 |
| --- | --- | --- |
| 整字 | 一个字的完整观察 | 永、橋 |
| 偏旁 | 字中可辨认的组成部分或字形 | 氵、木、可 |
| 结构 | 各部分的组合方式 | 左右结构、上下结构 |
| 笔画 | 基本或复合笔画的写法记录 | 横、长横、短横、横折钩 |

例如“河”可参考拆为左侧“氵”和右侧“可”；用于字典检字的部首另列。这里的“偏旁”用于保存这些字形部分的学习记录，和检字部首分别记录。笔画是一次书写轨迹，“横”请记在“笔画”用途中。

“我的分类”由你自由命名，如“基本笔画”“横画练习”“三点水观察”“待整理”。它与用途分开填写；已有笔记可点击“编辑”重新分类，留空显示“未分类”。

## 一个完整例子

1. 进入“知识库”，点击唯一的“新建笔记”。标题填“长横观察”，用途选“笔画”，对象填“长横”，分类填“基本笔画”。
2. 正文记录自己确认过的内容。操作示例：“临写前先比较长度、倾斜和起止位置，再对照所选范字检查。”这**不是教材原文或已审定写法**；来源应如实填自己的观察，或教材名称和页码。
3. 再建对象为“短横”的笔画笔记。即使分类同为“基本笔画”，它也能按对象里的“横”被找回。分类含“横”的其他用途记录也会一并关联。
4. 再建一条偏旁笔记，对象填“氵”或“三点水”，位置和层级按原观察填写，分类可填“三点水练习”。记录正文、来源和限制条件。
5. 回“查字”输入“河”。下方“笔画笔记 · 自动汇总”显示本字类型相关的记录，包括长横、短横等横类候选；“偏旁部首笔记”显示已识别偏旁对应的记录。无需先播放动画或选择某一笔。
6. 读每条笔记的来源和条件，结合例字确认哪些写法值得练习。不同位置的三点水记录也会列出，原位置和层级保持可见；展示相关内容不表示当前字可以直接套用。
7. 需要结构帮助时，按下文配置 AI 接口。最后到“数据管理”导出 JSON，确认文件保存成功。

## 自动匹配的规则

| 查到的参考信息 | 展示内容 |
| --- | --- |
| 本字包含“横”类型参考 | 所有用途中分类含“横”的笔记，以及笔画用途目标含“横”的记录，例如长横、短横、横折 |
| 竖、撇、捺、点、提、折、钩 | 分别按对应关键词查分类和笔画目标 |
| 横折钩等复合名称 | 分类或笔画目标含“横”“折”“钩”任意一项的记录 |
| 实际识别到氵 | 目标为氵的偏旁笔记，以及分类含氵或固定俗名“三点水”的记录 |
| 已知结构参考或 AI 结构分析 | 结构用途对应的候选笔记 |
| 一个精确汉字 | 仅关联这个字的整字笔记，简繁分别记录 |

笔画与偏旁区域均展示**全部相关候选**，按笔记 ID 去重；不按原位置或层级筛掉偏旁笔记，也不将它们视为当前写法已适用。原有条件、正文和来源保持不变。只有标题或正文出现关键词、分类和对象都不匹配的记录，可用知识库搜索框查找。

“水”和“氵”、“手”和“扌”等字形不自动等同。固定俗名按其真实字形识别，例如只有“水”的资料不会仅因“三点水”里有“水”字而自动命中三点水笔记。只有实际给出的部首与拆字参考参与偏旁关联；未知项不猜。

## 笔顺和类型参考的范围

站点包含 9574 条开源字形与轨迹记录，简繁按各自字符查找，不表示覆盖全部汉字。未收录轨迹的字仍可保存个人资料，但不会补造动画。

整字笔画类型参考覆盖其中 8776 字，其余 798 字保持未知。该类型表来自 CNChar，与 Make Me a Hanzi 动画为独立来源；不对应“动画第几笔”，也不判断长横、短横或具体书写方法。源编码有多种叫法时保留候选并提示不确定性。

另有 25 个常用字的有限逐笔名称参考，仅供单笔观察状态使用；歧义名称留空。逐笔名称的少量覆盖不影响整字类型汇总，单笔播放也不会改变本字相关笔记的范围。

动画来自开源字库，不是卢中南或其他书家真迹。单笔中线用于观察方向，不代表力度、笔锋或具体运笔方法。

## 配置和切换 AI

1. 在查字页点击“AI 接口设置”。填写服务商的**完整 HTTPS 调用地址**、模型名称和 API 密钥。需要 Chat Completions 兼容接口，通常地址以 `/v1/chat/completions` 结尾；以服务商文档为准。
2. 勾选“查字后自动分析间架结构”，点击“应用设置”。之后查字自动分析；也可关闭自动分析，按需点击“分析当前字”。模型调用可能产生服务商费用。
3. 随时重新打开设置，修改地址、模型或密钥并应用。切换地址时请重新填写密钥；应用新配置或查另一个字会取消旧请求，旧结果不会覆盖新字。
4. 点击“断开接口”可停止使用；字库参考、动画与笔记继续可用。

AI 分析单独标记为推演参考，不是教材原文或字库结论，不能提供虚构页码、书家特点或确定比例；需要人工核对。结果不会自动保存为个人修订或备份笔记。

设置只在本次页面有效，**密钥仅在内存，刷新后需重填**；不写入 GitHub、浏览器存储或导出备份。请求只发送当前汉字和部首、拆字、结构参考，**不发送个人笔记或 PDF**。请只配置自己信任的服务地址。

服务端必须允许当前网页跨域调用（CORS）。若提示连接失败，应检查完整地址、网络及服务端跨域设置；网页无法绕过服务商限制。可改用自己部署的兼容 HTTPS 代理，本站不提供共享密钥或代理。认证失败时检查密钥，额度受限时检查服务商账户与用量。

## 备份、换手机与导入

个人笔记与修订保存在当前设备、浏览器与站点来源，不自动同步到其他手机。

1. 在“数据管理”导出全部或勾选的笔记，确认 JSON 文件已保存。备份包含用途、分类、正文、来源和选定的个人修订；不包含整套字库、PDF、AI 配置或密钥。
2. 在另一台手机或浏览器打开同一网站，导入该文件。先查看新增、重复与冲突预览，再确认合并；冲突可保留本地、采用导入或复制为新笔记。
3. 回知识库核对数量、分类和正文。重复导入同一文件会识别重复内容，不应不断增加相同记录。AI 设置需在新设备重新填写。

v0.5 继续导出 `schemaVersion: 3`，兼容本笔记系统 v1、v2、v3 备份；v1 缺少分类的内容归为“未分类”。包含笔画用途的备份使用 v0.4 或更新网页导入。更早 v0.1 的学习记录属于另一种格式，请保留原文件。

清理浏览器数据、使用无痕窗口或更换域名可能让原笔记不可见，重要记录请及时导出。页面提示存储失败时，改动可能只留在内存，应立即导出并确认下载后再刷新或关闭。

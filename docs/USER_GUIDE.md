# 墨习写法资料库

## 记录写法

点击“资料库 → 添加写法”，选择笔画、偏旁或间架结构，再选择或输入记录对象，填写写法内容即可保存。标题自动生成；来源和例字可在折叠区域选填。

例如选择“横”，在正文中分别记下长横、短横的写法和变化。选择“偏旁”时可以输入“氵”或“三点水”，保存后统一关联氵。氵与水保留为不同对象。笔画、偏旁和间架结构按钮用于查看对应资料；同一对象的多条记录集中列出，正文分别保留。长横和短横旧记录集中在横画下，复合笔画仍单独整理。

## 查字自动关联

输入“河”后，页面自动展示相关笔画、氵、可等偏旁的记录，不必逐笔点选，也不要求设置位置、层级或分类。不能确定长横或短横时，横类资料一并列出。记录仍需结合例字判断适用性。

字形与动画覆盖9574条记录，整字笔画类型覆盖8776字，其余保持未知。已核对的有限名称用于逐笔观察；扩展笔顺名称仅作待核对参考，数量不符时不套用。动画不是书家真迹，轨迹不代表笔锋或力度。

## 间架结构与 AI 接口

基础结构可以记录左右结构、上下结构、包围结构等；具体布局可以记录左窄右宽、上紧下松、左收右放等，从记录对象列表选择。两种资料都归在“间架结构”。

在查字页打开“AI 接口设置”，填写可信服务的完整 HTTPS 调用地址、模型名和密钥。接口使用 Chat Completions 兼容协议，并须允许网页跨域调用。开启自动分析后，查字会请求基础结构和布局特点；也可关闭自动分析，手动点击分析。API 可随时更改，旧请求取消，新配置立即生效。

例如 AI 返回“左右结构”和“左窄右宽”，页面分别列出两类已保存资料，并标注布局匹配依据和“AI 匹配参考”。没有足够依据时可以不返回布局标签；AI 结果不是教材原文或规范认证，不会覆盖个人记录。不配置接口时，基础结构仍可依字库参考展示，具体布局不会假装经过 AI 分析。

模型请求只包含汉字及公开字库参考，不发送你的笔记、个人修订或 PDF。设置和密钥仅在本次页面内存中保存，刷新后重新填写，不进入 GitHub 或笔记备份。模型服务可能收费。本站不提供共享密钥或模型代理。

## 旧资料与备份

旧标题、原文、来源、分类、位置、层级和适用条件继续保留；编辑旧记录时可展开附加信息。旧整字记录也保留，不作为普通新建入口。记录不自动合并，不会被 AI 改写。

新版导出使用 schemaVersion 4，仍兼容导入笔记备份1、2、3、4。新备份应在v0.6或更新网页导入。更早v0.1学习记录是另一种格式，请保留原文件。

个人资料保存在当前设备、浏览器和站点来源下，不会自动云同步。定期在“数据管理”导出JSON并确认文件已保存；换设备时导入，检查预览和冲突后确认合并。重复导入会去重。存储失败时，先立即导出内存资料再关闭页面。
